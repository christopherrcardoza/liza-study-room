Facial animation — NVIDIA Audio2Face-3D

The mouths are driven by NVIDIA Audio2Face-3D-v2.3-Mark and by reduced lip-sync data derived from it, under the NVIDIA Open Model License. Section 3.1 of that agreement requires both a copy of the agreement and a file named Notice carrying one exact sentence. Both ship here:

Two things this page does not answer

CourtSim's own code has no licence of its own. There is no LICENSE file in this repository, which by default means all rights reserved. Whether that is right for a build handed to students is a decision for the founder, and it has not been made.

This page covers software and model assets only. It does not cover the written study content or any reference material. That is a separate question and nothing here speaks to it.
